1. **IME candidate list under a mid-composition layout move (SR1, TSF).** F7live 20/21 and F8 18/19 each fail only `candidate-window-follows-layout-move`: the renderer re-places the IME windows (`ime_replace reason=layout`) but Windows 11's modern IME does not move the already-open list; a TSF text store (`ITfContextView::GetTextExt`) is the likely fix (`probes/sr0-b/native-interaction/out/native-ime-f8-tuple10.txt:606`, `native-ime-f7live-tuple10.txt:616`).
