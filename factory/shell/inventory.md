# Shell journey inventory (F12)

Package contracts and discoverable ViewRight/SliceApp sources only. Journey inventory is demand evidence; it does not claim shell acceptance or prove service integration. Tauri adapters, runtime behavior, full consumer coverage and SR2–SR4 gates remain unverified.

| Journey | Trigger → action → observable outcome | Demand / service boundary |
|---|---|---|
| **Navigation & command discovery** | User chooses a sidebar destination or opens app command/jump UI. **Action:** Filter visible groups; move by orientation-aware arrow/Home/End; select destination or run a ranked command. **Outcome:** Selected destination/command becomes active; filtered settings rows can be revealed and palette/dialog outcomes can be observed. | Pilot: `text, scroll, padding-frame`. Services: App-owned destination state; optional command registry and native bridge for menu/deep-link actions. |
| **Settings navigation, editing & persistence** | User opens Settings, searches for section/entry, or changes a setting. **Action:** Search and select section; edit injected controls; call SettingsContext.set/patch through supplied backend. **Outcome:** Active section and search reveal update; values save, errors surface and revisions may reject stale writes. | Pilot: `text, scroll, toggle, disabled, padding-frame`. Services: SettingsBackend load/patch/subscribe; Tauri-backed rightkit-settings adapter in production; section-specific adapters. |
| **First-run onboarding & resume** | User launches before setup state is complete, or reopens setup. **Action:** Review legal gate; request permissions; install/select models; activate license or skip; continue/back/finish; state is loaded and saved per step. **Outcome:** Progress/completed/skipped and legal acceptance persist; finish/skip callback runs only after successful save; failures display. | Pilot: `text, scroll, toggle, disabled, padding-frame`. Services: SettingsBackend; PermissionsBackend; ModelsBackend; optional LicenseBackend; optional app-owned LegalReceiptPort; callbacks. |
| **Media playback** | User opens audio/video, presses play, seeks, changes speed/volume, or playback decode fails. **Action:** Play/pause/replay; seek; adjust speed/volume; optionally prepare compatible media; retry/open original/open OS player. **Outcome:** Playback time/state and decode errors update; external-open callback can hand off. | Pilot: `image, stack-overlay, text, padding-frame, disabled`. Services: MediaAdapters resolveSrc/preparePlayback/cancelPlayback/setFullscreen; app owns playback preparation implementation and notification/log hooks. |
| **Image view, edit & export** | User opens image and selects crop/text/adjustment/sibling navigation. **Action:** Page sibling images; crop or add text; invoke save, print, resource accounting or external notifications. **Outcome:** Canvas preview and selected image update; export/print reports saved path or cancellation/failure. | Pilot: `image, stack-overlay, text, scroll, padding-frame`. Services: MediaAdapters listImageSiblings/listSystemFonts/saveImage/printImage/acquireResource; app owns dialogs/filesystem writes. |
| **PDF read & navigate** | User opens PDF in ViewRight or document surface. **Action:** Load bytes/url/loader; page previous/next/jump; zoom/fit/rotate; outline/thumbnails; find and follow safe external links. **Outcome:** Read-only page view changes; page count/error/loading/view state emitted to host. | Pilot: `image, scroll, text, padding-frame, disabled`. Services: PdfSource supplied by host; optional openExternal adapter; host may persist PdfViewState. |
| **Legal agreement & re-acceptance** | Missing/outdated accepted version opens gate; user reads documents and chooses eligibility basis. **Action:** Open terms/privacy URLs or callbacks; select individual/enterprise; agree or quit. **Outcome:** Agree callback records version/hash/timestamp/basis; save failures remain visible; newer version can re-prompt. | Pilot: `text, scroll, toggle, disabled, padding-frame`. Services: App-owned acceptance receipt is truth when injected; onboarding SettingsBackend stores progress; external URL opener optional. |
| **Keyboard shortcuts & rebinding** | User presses configured chord, ? help chord, or opens shortcuts settings. **Action:** Dispatch chords/sequences with typing-target guard; open help; expose effective chords and rebinding override. **Outcome:** Command runs or remains unhandled; help lists visible active bindings; override state reflected. | Pilot: `text, scroll, padding-frame`. Services: ShortcutRegistry; platform resolver; persistence adapter for overrides supplied by app/settings integration. |
| **Native menu, tray & deep links** | Native menu/tray/deep-link action arrives with registered id. **Action:** Subscribe to AppShellBridge.onMenuAction; dispatch matching command or shortcut id. **Outcome:** Registered action executes in app shell. Actual tray/menu construction and OS lifecycle not specified by these package sources. | Pilot: `text`. Services: Optional AppShellBridge.onMenuAction; host Tauri menu/tray/deep-link adapters. |
| **Confirm, prompt, palette & help overlays** | App requests confirmation/prompt, or user opens command/help overlay. **Action:** Present queued dialog; submit/cancel; dismiss via Escape/backdrop; focus trap; select/rank command. **Outcome:** Promise resolves true/false or string/null; palette command runs after close; focus is returned/managed. | Pilot: `text, stack-overlay, padding-frame, disabled`. Services: ShellProvider dialog and command state; app supplies command callback. |
| **Shell & app state persistence** | User changes theme/settings/onboarding progress or edits SliceApp rows. **Action:** Theme store reads/writes choice; SettingsBackend stores settings; onboarding patches progress; SliceApp model persists edits. **Outcome:** Choice and app state reload from their designated store; SliceApp row edits/ordering are serialized. Storage ownership differs per feature. | Pilot: `toggle, text, padding-frame`. Services: ThemeStorage/localStorage default; SettingsBackend/rightkit-settings; app-owned LegalReceiptPort; SliceApp RowStore (source evidence only). |
| **Check, install & recover update** | User opens ViewRight Updates settings or install previously downloaded update. **Action:** Check for updates; toggle auto-check; install/download external; on failure retry; protect dirty PDF before replacement. **Outcome:** State changes through checking/current/available/installing/failure; dirty document blocks unsafe replacement with error. | Pilot: `text, scroll, disabled, padding-frame`. Services: ViewRight update/license service and OS package replacement; dirty-document recovery guard. |
| **Error & startup recovery** | A component fails or startup/update detects a recoverable state. **Action:** ErrorBoundary exposes recovery action; onboarding load failure offers Retry; update gate may preserve unsaved document. **Outcome:** Retry clears boundary or reloads setup; recovery must not discard dirty edits. Package evidence covers only those explicit paths. | Pilot: `text, disabled, padding-frame`. Services: React error boundary; settings loader; app document saver/update recovery services. |
| **SliceApp sample reorderable editor** | User inserts, edits, moves or deletes a row. **Action:** Focus row; edit text; insert above; nudge up/down or drag reorder; delete. **Outcome:** Rows visibly update and model persists edits; sample exercises shared SwiftUI/SwiftRight view source. | Pilot: `text, scroll, padding-frame`. Services: SliceApp EditorModel and RowStore persistence. |

Evidence: 22 source receipts (absolute path, SHA-256, line number and line text) in [`inventory.json`](inventory.json). `demand.json` provides flattened demand records, named pilot IDs and 61 extended demands awaiting registry mapping.

Run `python -m factory.shell` from repository root to rescan source hashes/anchors and validate inventory/demand consistency. Missing sources or changed evidence fail the check.
