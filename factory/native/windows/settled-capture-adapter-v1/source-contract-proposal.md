# Prospective issued metadata & measured joins

Current Count1 remains diagnostic. Legacy normalize.py requires20 & mints capture IDs, host/clock IDs & provenance timestamps. This adapter accepts only Count1 or complete20 batch bodies, preserves actual run indices, measures archived bytes through explicit reader refs & never calls legacy normalizer. UIA/PrintWindow channel values can be inspected independently from complete source/admission qualification.

Minimal NEW capture successor additions:

1. Root issues immutable metadata BEFORE launch: kind `factory-prelaunch-capture-metadata-v1`, version1, runRoot, expectedCount1/20, exact case hash/id, recipe ref, source plan ref, sourceHash, compiler receipt ref, exe ref, renderer ref, tuple candidate ref, frozenTupleBound=false. `captures` has ordered run1..N entries with allocated captureID, imageID, producer-createdAt/sourceHash/producer & measured-source host/clock identity declarations. IDs are assigned by issuing producer; adapter never derives them from case/run.
2. Parent admission verifies metadata raw SHA & all source/case/compile/exe/render refs before acquiring window. Source-owned launch receipt binds issuedMetadata SHA, exact metadata captureID/run/runRoot/count, admitted driver contract SHA, owned PID/exe/start/HWND, source/case & beforeLaunch UTC time. Same raw metadata ref/hash enters outcome & native-observation. A posthoc sidecar cannot substitute this producer join.
3. Measurement receipt records owned host ID/hash & clock ID/correlation hash from admitted source. Clock correlation references actual archived launch/measurement bytes. Metadata cannot claim an unmeasured host/clock. Existing native-observation lacks these fields.
4. Isolated UIA path writes source-owned snapshot-ready receipt containing worker config/contract/exe/owned identity/observation/exit refs, scalar UIA hash, natural preCleanup kernel0, sealed raw joins & UTC ready time. Pixel receipt records snapshot-ready receipt SHA & actual pixel start UTC; owned-close records same SHA & close UTC. Adapter verifies worker finish <= snapshot-ready <= pixels <= WM_CLOSE with integer100ns timestamps. Current capture-v2 calls Assert-FactorySnapshotReady at these points, but no durable worker-before-pixels ordering join was inspected in existing actual witness.
5. Final-release certificate remains separate receipt. Original outcome preCleanup kernel0, primaryError empty, no kill, original15s exit path & two sealed streams are mandatory channel eligibility. A final kernel0 certificate authorizes lock release only. It cannot alter original deadline failure or mint successful native-observation.
6. Native observation raw `files` binds issued/launch/measurement/snapshot-ready receipts & canonical identities. Adapter reads actual bytes, checks joins, assembles schema capture using ONLY issued metadata fields plus measured channel values. F10 windowsExitProof & MacOrigin references must still be supplied & independently verified through archived readers. Historical CompileRequest absence remains explicit admission issue.

Source contract changes must occur in NEW factory capture namespace, then frozen-source review & actual controls. Renderer/host/runtime/ABI stay unchanged. Unknown provider/layout/events/animation/text exports remain empty channels with explicit availability issues. Candidate tuple metadata does not imply tuple closure, parity or promotion.
