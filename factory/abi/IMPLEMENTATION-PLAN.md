## Proposal resolutions & implementation requirements

1. **Single geometry clip cannot describe actual primitive masks.** paint_tree resets clip stack per node; ancestor node bounds/clips are not inherited, & one node may contain disjoint sequential ClipPush/Pop regions. Former proposal ancestor-intersection wording was unsupported by real0.6 paint path & is now corrected. Preserve renderer behavior; do not invent ancestor clipping or collapse disjoint masks into false single clip. Revised node_geometry.clip denotes client viewport/common actual clip applying to every primitive; per-primitive masks remain unavailable/held. If precise primitive clipping becomes obligation, separate bounded proposal is needed. Geometry baseline must reflect primitive translation; node bounds do not move with primitive transforms.
2. **Paint counters currently ignore fallible results.** WrappedLine.paint & paint_image results are discarded; counts cannot truthfully mean successful draw submissions unless results are observed. Rect/underline calls submit scene quads; text wraps multiple paragraphs. Define text_runs_drawn once per primitive whose required paragraph submissions all succeed, or document partial-submission failure without claiming completed primitive. White background is not host RECT primitive & must stay excluded. Zero-size/empty clipping controls distinguish call execution from visible coverage.
3. **No GPU completion/presentation observation exists in renderer wrapper.** paint_root end, PH_PRESENT & tick timestamps are CPU times. Backend surface/fence hooks are prerequisite; until present feedback exists use submitted-without-feedback record, presented_ns0/flag0. Readback fence completion supplies GPU completion evidence only. No DWM nominal timestamp, Present return or vblank edge substitution.
4. **Bootstrap current implementation contradicts proposed legacy prefix negotiation.** Current lib.rs rejects caller_size88 once BootstrapInfo grows108 rather than copying min bytes. Postclosure change must build local initialized info & copy exactly bounded bytes after minimum-readable-prefix check; old loader receives abi_minor7 & rejects before API call. Never whole-write108 into88.
5. **Retaining newest2 immutable GPU frames requires preservation before swapchain reuse.** Starting copy only at frame_acquire is too late if completed target was overwritten. Either provider retains immutable rendered textures or backend queues GPU copy into newest2 archive textures every completed frame. No exposed flag enables archive-on-demand; existing six-function contract therefore implies continuous bounded preservation sufficient for historical lookup. Measure archive cost with exporter idle; do not silently implement latest-only or force repaint.
6. **Byte budget & pinned history pressure need explicit policy.** Two eligible newest surfaces plus four unique retained handles can exceed256MiB at64MiB each. Account unique GPU+CPU storage/readback staging, not handle count; share backing data for handles of same frame, reject acquisitions that require excess storage, evict unpinned old archives. Revised contract: if pins leave insufficient space to preserve newest completed frame, rendering/presentation & timing records continue; newest capture availability is skipped & latest acquisition returns EMPTY. Older eligible archives remain explicit historical lookups only. It must never return stale older pixels as latest, block paint waiting for release or drop actual display frames for capture capacity. Next successfully preserved newest completed frame restores latest availability; acquisition itself never forces repaint. Geometry history stores only newest2+retained frames;256 timing records need no full node snapshots.
7. **Occlusion & render generation tracking absent.** Existing WIN_ACTIVE distinguishes activation, not occlusion/minimize. Observe minimize/surface lifecycle/device loss with backend/native window state; unknown occlusion remains0 unless independent observation supports stronger value. Resize/DPI invalidates latest-generation eligibility before new surface completes, even if old viewport atomics update only during paint. Already retained historical handles preserve metadata.
8. **Frame gauges are not frozen live_nodes semantics.** stats.live_nodes currently sums tree/runs/images; do not add frame objects to that existing gauge. Internal FrameStore counters & test receipts verify frame cleanup without changing0.6 stats layout/meaning.

Private font registration/resource selection/resolved identity remains separate provider gap per proposal. Existing Measured stores family-derived shaped runs & geometric data, no resolved resource hash/face collection. External private DirectWrite Tinos control is not renderer registration. No font exports or measurement selectors are added in this plan.

## Minimal components & GPU policy

New `src/frame.rs`: FrameStore, generation-tagged FrameHandle slab, immutable FrameSnapshot containing captured node geometry/draw counts/version/dimensions/scale/occlusion & provider surface reference, newest2 eligibility, max4 handles,256 record ring, checked budgets & lifecycle transitions. State machine: scene-submitted -> GPU-completed -> retained eligible; independent presentation feedback appends outcome/timestamp. Acquisition pins completed immutable scene/surface identity, queues readback; copy remains E_BUSY until asynchronous completion. Once returned, frame_info timing validity is frozen; later presentation is discoverable via frame_records for same frame_id, not mutation of copied info.

New `src/frame_provider.rs`: thin boundary for pinned backend ownership, submit token, immutable archive/copy, completion polling, minimize/generation/device state & optional real presentation feedback. GPU worker owns backend resources only; host pointers, UI RefCell, Swift callbacks & GPUI foreground executor never cross worker boundary. Use renderer/native device's supported copy queue/context discipline rather than concurrent immediate-context calls. Submit copy after matching render commands, signal GPU completion query/fence, poll nonblocking outside native/IME borrows; map only after completion. No UI fence waits, message pumping, busy loops, forced Flush per poll or forced extra frame. Completion wakes existing signal/drain path without invoking host callback from worker.

Provider copy/readback converts mapped row pitch/channel order to tightly packed RGBA8 premultiplied sRGB top-left, clears transparent RGB, checks every dimension/stride/byte product & unmaps promptly. Current white opaque background implies alpha255; underlying image alpha test is composited, not recovered surface transparency. Preserve swapchain/HDR format provenance; unsupported conversion/readback returns unsupported/platform failure instead of fake pixels. Check generation token before publishing callback completion; old-generation captures may only complete already pinned history.

Readback worker cancellation must acknowledge device-resource disposal safely; window close retires public handles immediately after allowed close-callback release phase, detached late completions discard without repopulating state. Device loss invalidates latest surfaces & pending operations, records truthful unavailable/submitted history & never uses old target. Shutdown does not wait synchronously for GPU on host UI thread.
