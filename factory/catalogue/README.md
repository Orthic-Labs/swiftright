# F1 SDK catalogue

Run from repository root with the factory environment:

```sh
factory/.venv/bin/python -m factory.catalogue extract
```

`extract` invokes `swift-symbolgraph-extract` for SwiftUI & SwiftUICore, emits extension-block graphs into ignored `factory/out/catalogue/raw/`, merges graph files by precise USR, audits SDK interfaces, and writes canonical evidence under `evidence/`. Use `--developer-dir`, `--sdk`, `--target`, `--out`, and `--evidence` to pin another local toolchain. `merge` rebuilds evidence from supplied graph and interface paths; `audit` reruns v1 name reconciliation; `audit-v2` reconciles by enclosing type/extension, kind, labels, and parameter types; `audit-v3` adds normalized generic `where` constraints & Swift-operator operand matching; `audit-v4` also normalizes all pinned SDK module qualifiers & uses exact return types as positive disambiguating evidence; `audit-v5` uses compiler-probed conditional branch selection from `evidence/tilde-sendable-compiler-probe.json`. Later audits accept optional `--comparison-graphs` for another target's graph set.

The checked-in catalogue uses Xcode 27 RC, macOS 27.0 SDK, arm64 macOS 27 target, and `-emit-extension-block-symbols`. The v1 audit remains `incomplete-name-level-audit`. The separate arm64e comparison uses same SDK; its 108,272 USRs exactly match arm64 graph USRs. V1–v4 evidence snapshots remain unchanged. V4 maps 7,999 of 12,635 rows. V5 runs exact `#if compiler(>=5.3) && $TildeSendable` probe binary for both arm64 & arm64e against same SDK; both stdout byte hashes match & select true branch. V5 marks 2,893 eligible else-branch rows `inactive-compiler-conditional`, annotates 210 further inactive rows while retaining their higher-priority macOS-unavailable classification, and keeps active conditional branch rows separate: 1,831 mapped, 1,056 active-unmapped, 6 ambiguous, & 210 macOS-unavailable. Overall v5 retains 839 macOS-unavailable rows, 23 documentation/SPI-hidden rows, 218 ambiguous rows, & 1,438 unexplained rows. Audit remains incomplete: 2,712 active rows remain unmapped, ambiguous, or unexplained; inactive rows are not hidden or counted as API matches. This is symbolgraph-to-interface reconciliation evidence, not a claim of SDK API completeness. See `evidence/interface-audit-v5.json` & `evidence/tilde-sendable-compiler-probe.json` for rows, compiler output, hashes, target commands, and toolchain.
