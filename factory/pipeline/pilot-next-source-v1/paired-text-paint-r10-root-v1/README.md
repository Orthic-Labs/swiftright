# Text paired production reader r10

Source-only successor to `paired-text-paint-r7-v1`. It validates admitted Count1 & Count20 producer graphs before reading native evidence, then reuses bounded raw Text reader. It requires exact case, tuple, source, recipe, runtime, renderer, serializer, plan, compile receipt, executable & MTA worker joins. Every Windows run requires original retained-handle exit, sealed streams, terminal worker proof, & parent certificate. Mac rows preserve raw AX, pixel, timing & handle holds.

Inputs:

```text
--mac-root factory/oracle/mac/text-origin-r11-root-v1/observed-paint-mac20-r1
--count1-graph factory/native/windows/pilot-text-paint-root-v2/capture-count1-r12-root-v7-sources
--count20-graph factory/native/windows/pilot-text-paint-root-v2/capture-count20-r10-root-v3-sources
--windows-root <explicit actual observed-native20-r10 archive>
```

  --mac-root factory/oracle/mac/text-origin-r11-root-v1/observed-paint-mac20-r1 \

Report remains `observed-diagnostic`, with semantic agreement, timing, raw evidence & parity held separately. No qualification, golden or frozen claim is emitted.
